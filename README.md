# THARA

THARA is a Palestinian tourism and e-commerce website that allows users to explore Palestinian cities, discover cultural heritage and local products, plan personalized trips, and support local artisans.

## Quick start

```bash
git clone <REPO_URL>
cd thara
npm install
npm run dev        # builds CSS and watches for changes
```

Open `index.html` in the browser (use the VS Code "Live Server" extension for auto-refresh).
Open `styleguide.html` to see all colors, fonts and components.

## Project structure

```
thara/
├── index.html            Home page
├── styleguide.html       Visual reference of the design system
├── pages/                One HTML file per page (cities.html, shop.html, ...)
├── css/
│   ├── input.css         Our shared components (edit this)
│   └── output.css        Generated by Tailwind (never edit, not in Git)
├── assets/images/        Images
├── tailwind.config.js    Colors, fonts, spacing tokens
├── DESIGN-SYSTEM.md      The design rules - read before coding
└── CONTRIBUTING.md       Git workflow - read before your first commit
```
